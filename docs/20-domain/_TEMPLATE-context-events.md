## 反例（不要这样做）

| ❌ 错误 | 问题 | ✅ 正确 |
|---|---|---|
| `PlaceOrderEvent` | 祈使式，像命令不像事实 | `OrderPlaced` |
| `OrderEvent(type = "place")` | 用字符串区分类型，丢失类型安全 | 每种事实一个密封类子类型 |
| 事件里塞整个聚合对象 | 耦合、序列化陷阱 | 只带 ID + 必要快照字段 |
| 事件只带 ID，订阅者回头查上游 | 引入同步依赖 | 携带订阅者所需的快照 |

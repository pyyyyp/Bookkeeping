## 使用规则

1. **发现即记录**：一旦你在写代码时产生「这里应该……吧？」的念头，立刻停下来记一条 Q。
2. **只降级不猜测**：可以在代码里放一个**集中的**降级常量，但必须标 `TODO(Q-xxx)`。
3. **阻塞要明说**：在汇报的「风险 / 待决策」栏列出所有影响本轮验收的 Q。
4. **解决要闭环**：得到答案后 → 更新 `glossary.md` / `<context>-model.md` / `REQ-*.md` → 修改代码 → 把 Q 移到「已解决」→ 提交信息引用该 Q 编号。
5. **禁止**：把猜测散落在多个文件里；用「通常」「一般」「应该」描述业务规则。

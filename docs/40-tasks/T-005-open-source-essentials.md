## 目标

让仓库达到「别人 clone 下来能理解、能构建、知道数据去哪了」的程度。
这不是锦上添花——**通知监听在技术上可读取全部通知内容**，
开源项目若不说清数据边界，是对使用者的不负责任。

## 变更清单

- [ ] `LICENSE`（**没有 LICENSE 时默认「保留所有权利」**，别人 clone 了也不能合法使用）
- [ ] `README.md`：项目是什么、截图、构建前置条件（JDK / Android SDK / 版本）
- [ ] `PRIVACY.md`：明确声明
  - 通知监听的用途**仅限**解析金融类通知，且解析在本机完成
  - 定位数据仅用于工时判定，不上传
  - **无任何网络上传行为**（v1 无后端）
  - 数据存放在何处、如何导出与删除
- [ ] `CONTRIBUTING.md`（若 T-004 未创建）
- [ ] 复核 `.gitignore`：确认 `local.properties`、keystore、`.tools/` 均被忽略
- [ ] 复核 git 历史中无个人配置与密钥泄漏

## 验收

- [ ] 在干净目录 `git clone` 后，按 README 步骤能构建通过
- [ ] `LICENSE` 已选定并加入（需用户决定许可证类型：MIT / Apache-2.0 / GPL-3.0）
- [ ] `PRIVACY.md` 与实际实现一致（**不是愿景声明，是与代码对应的说明书**）
- [ ] `git log --all --diff-filter=A --name-only` 复核无密钥文件进入过历史

## 待用户决策

|---|---|---|

| 是否现在就公开 | 先私有仓库 / 直接公开 | 影响提交历史是否已可接受 |

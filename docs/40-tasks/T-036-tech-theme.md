## 目标

用户："**参考现在已经有的一些记账软件，最好更有科技感一些**"，并要求"**按正常手机的比例**"。

这一轮做三件事，它们互为前提：

1. **锁竖屏** —— 手机记账 App 的通行做法；开发机是 1080×1920 横向，不锁就会把竖屏布局
   拉成"桌面感"（见 `.tools/shots/before-ledger.png`，那正是问题本身）；
2. **设计底座**（`core:ui`）：深色科技感 token + **语义色插槽** + 一组通用组件；
3. **记账页重排**：把六大块从"裸文本平铺"改成"卡片 + 主次 + 比例条"。

⚠️ **逻辑一行不改**：所有数据仍来自原有 ViewModel 与读模型（`REQ-002`~`REQ-011` 的验收标准
全部照旧）。这是**纯展示层**改动 —— 也正因为如此，VM 测试与追溯矩阵的 AC 证据都不受影响。

没有这一步，`T-030` 的规则再对也**没人能喂它数据**。

## 两处刻意的取舍

1. **不用地图选点**：地图 SDK 是新依赖（须先问）。"我就站在干活的地方" → **把当前位置设为圆心**
   是这个场景最自然的输入，也不需要任何新库。
2. **不引入 `navigation-compose`**：版本目录里备着它、注释也写着"出现第二个页面时引入"，
   但引入依赖属于必须先问（`Q-028`）。两个页面用一个 `when` + 顶部切换就够 ——
   **代价明说**：这是临时的，页面变多会变丑。

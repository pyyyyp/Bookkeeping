# 法定节假日与调休数据（Calendar 上下文）
#
# ⚠️ 本文件**目前是空的**，这是刻意的：法定节假日与调休由国务院每年发布，
#    是**现实世界的事实**。凭记忆或推测填进来，就是把猜测写进"唯一事实源"，
#    而错一天的代价是**工资算错**。机制已就绪（见 docs/30-architecture/ADR-0011-workday-calendar.md），
#    填数据是**每年一次的手工步骤**。
#
# 格式（空行与 # 开头忽略）：
#   <yyyy-MM-dd> holiday   ← 法定节假日（加班 3×）
#   <yyyy-MM-dd> workday   ← 调休：被调成工作日的周末
#
# 一年更新一次。更新时请在上面的注释里写下数据来源与公告日期，例如：
#   # 来源：国务院办公厅《关于 2026 年部分节假日安排的通知》（2025-11-XX）
#
# 空着时的行为：该年按周末规则判定，并在判定结果里标 missingYear = true
# （调用方据此提示一次 —— 而不是让用户以为"今年没有节假日"）。
